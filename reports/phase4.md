# tidal 第四阶段报告（公开版，2026-10-08，UTC+8）

> 公开仓库里的脱敏版本：只包含**公开数据**上的结果、只用公开数据训练的模型的数字，以及与数据无关的结构 / 延迟测量。
> 凡是用到部署方真实聊天（训练或评测）的数字只留在私有报告里，这里只给定性结论和预注册规则的判定结果。
> 公开数据集不再分发；本阶段训练的权重一律不发布（包括第三方教师模型 SenseVoice-Small 的权重）。

## 1. 做了什么

预注册规则（训练前写入工作日志）：
- **主干（4B）**：在真实数据验证集上，3 个微调种子的平均 loss 最低者胜出；与最优差距 ≤ 0.005 时选单线程流式 p95 延迟更低者。测试集数字只报告，不参与选择。
- **情绪接入（4A）**：只有当"加情绪"配置的平均真实 val loss 低于不加情绪的对照时才采用；测试集差异无论好坏都报告。
- **语音情绪接入音频轮次**（14:40 预注册，运行前）：按事件类型（换人 / 附和）分别判定，只有在训练折内部验证会话上的平均 log-loss 下降时才采用。

1. **4A 情绪**：文本情绪头（冻结 bge-small-zh 嵌入 + MLP，13.4 万参数，8 类共享标签 + 效价 / 唤醒度），
   语音情绪头（冻结的流式音频编码器 + GRU(64)，4.2 万参数，20 ms 一步）；SenseVoice-Small 只做离线教师。
   再把情绪接入"何时说话"：文本情绪作为事件特征接入事件流模型；语音情绪作为对方语音的特征接入音频轮次决策。
2. **4B 主干对比**（同一协议：公开数据预训练 1 次 → 真实 + LLM 合成数据微调 3 个种子，约 0.47–0.50M 参数）：
   GRU（现状）、RoPE + KV 缓存的因果 Transformer（`tx_kv`）、Mamba-3 SISO、Mamba-3 MIMO（秩 4），
   外加一个消融 `m3_ablate_m2`（同一份 Mamba-3 代码关掉梯形离散化和 RoPE、R = 1，相当于 Mamba-2 / SSD 式递推，
   但保留 BCNorm 和偏置，所以不是原版 Mamba-2 模块）。Mamba-3 是按论文写的纯 PyTorch CPU 实现（含分块 SSD 形式），
   递推形式与分块形式、逐步流式与整窗前向的一致性都有测试（`tests/test_phase4.py`）。
3. **4C 连续体记忆**（Nested Learning / Hope 的 Continuum Memory System，Behrouz et al., NeurIPS 2025；Titans 的惊奇度驱动测试时记忆）：
   冻结胜出主干，在编码器输出上加多时间尺度的低秩残差适配器（会话级 / 群级 / 部署级），只用自监督 VAP 目标在线更新，
   严格因果（某个目标只有在流时钟越过它的时间窗之后才会被用来学习）。**只做影子回放评测，不参与线上决策。**

## 2. 4A 情绪

### 2.1 文本情绪头（公开数据；3 个种子平均，括号里是只预测先验分布的基线）

| 评测集 | n | macro-F1 | 先验基线 |
|---|---|---|---|
| BRIGHTER 中文（人工多标签，官方测试集） | 5,284 | **0.500** | 0.289 |
| BRIGHTER 英文 | 5,528 | 0.434 | 0.406 |
| 中文多情绪对话（简体，次要） | 388 | 0.736 | 0.281 |
| GoEmotions 英文（8 类归并） | 5,427 | 0.325 | 0.222 |
| GoEmotions 中文机翻（次要） | 1,017 | 0.440 | 0.221 |

- 校准好（ECE 0.007–0.026）。唤醒度 / 效价与 BRIGHTER 人工强度的 Spearman：中文 0.32 / 0.67，英文 ≈ 0 / 0.33。
  英文弱，原因是编码器是中文模型。
- 延迟（单线程）：bge 嵌入 1.1 ms / 条（phase 1 起就已经在算），情绪头 0.21 ms。

### 2.2 语音情绪头（公开数据）

CREMA-D（英文表演语音，6 类，按演员留出 18 名测试演员，n = 1,476）：

| 配置 | macro-F1（3 种子） | 唤醒度 vs 人工强度 Spearman |
|---|---|---|
| 只用 CREMA-D | 0.517（0.499 / 0.522 / 0.530） | 0.39 |
| + SenseVoice 软标签蒸馏（MagicData 中文对话片段） | 0.519（0.514 / 0.541 / 0.502） | 0.40 |
| SenseVoice-Small 教师本身（软后验，限 6 类） | 0.492 | — |

- SenseVoice 的硬标签在 CREMA-D 上 95% 输出 EMO_UNKNOWN，所以改为读取它情绪位置的 CTC logits 做软后验
  （`tidal/sv_soft.py`，与 sherpa-onnx 硬标签核对过）。
- 中文对话（MagicData）上教师 93% 判为中性，学生与教师的一致率约 0.93，但 kappa ≈ 0：**中文语音情绪基本没有学到有用信号**。
  没有找到许可证清楚、人工标注的中文语音情绪数据集（见 [phase4_datasets.md](phase4_datasets.md)）。
- 流式开销：每个 100 ms tick 0.12 ms（p95 0.16 ms），单线程。

### 2.3 接入"何时说话"

- **文本情绪 → 事件流模型（真实数据，定性）**：按预注册规则**采用**。在 GRU 上，加情绪配置的平均真实 val loss
  低于不加情绪的对照，也低于"只加一个有无文本标记、情绪值置零"的对照（排除"多了几列输入"本身的作用）；
  在 4B 胜出主干上重复同一检验，结论相同。测试集：说 / 等 / 不说（`y_act`）头和 VAP loss 在两个测试切分上都变好，
  EOT 在时间切分上略差（CI 触及 0），其余头大多跨 0。
- **语音情绪 → 音频轮次（公开数据，MagicData 按说话人对 3 折）**：按预注册规则**不采用**（换人、附和都不采用）。

| 事件 | n | 内部验证 log-loss（无 → 有情绪） | 测试 PR-AUC（无 → 有） | 有 − 无（95% CI） |
|---|---|---|---|---|
| 换人 / 保持 | 1,284 | 0.608 → 0.618 | 0.587 → 0.562 | PR-AUC −0.024 [−0.052, −0.000] |
| 附和 | 164,211 | 0.029 → 0.047 | 0.007 → 0.004 | ROC-AUC −0.186 [−0.253, −0.123] |

  附和上情绪特征明显过拟合（更像是在识别会话 / 说话人，而不是情绪）。语音情绪头只在影子接口里输出（`ControlOut.affect`），不进入决策。

## 3. 4B 主干对比

公开测试流：5 个公开来源（Telegram 群聊、IRC、Twitch 直播聊天、CANDOR、AISHELL-4）的 pub_test 切分，随机 40,000 个事件，块自助法 CI。
这些只是公开数据预训练模型（P4pub_*）的数字；真实数据上的 val / test 数字只在私有报告里。

| 主干 | 参数 | 公开测试流 VAP loss（Δ vs GRU，95% CI） | 公开预训练耗时* | 流式单步 p50 / p95（1 线程，eager） | 状态大小 | ONNX 流式单步（ORT p95，与 PyTorch 最大误差） | 真实 val 排名（3 种子平均） |
|---|---|---|---|---|---|---|---|
| GRU（现状） | 499,042 | 0.2619（基准） | 31 min | 0.309 / 0.392 ms | 1.5 KB | 单步，0.082 ms，2.5e-07 | 5 |
| RoPE + KV 缓存 Transformer | 459,362 | 0.2610（-0.0009 [-0.0022, +0.0007]） | 38 min | 0.639 / 0.84 ms | 128.0 KB | 环形 KV 缓存定长单步，0.204 ms，6.0e-07 | 3 |
| Mamba-3 SISO | 469,890 | 0.2603（-0.0017 [-0.0029, -0.0000]） | 81 min | 1.012 / 1.354 ms | 68.5 KB | 单步，0.452 ms，9.5e-07 | 2 |
| Mamba-3 MIMO（秩 4） | 466,818 | 0.2601（-0.0019 [-0.0028, -0.0009]） | 201 min | 1.157 / 1.701 ms | 80.5 KB | 单步，0.981 ms，1.5e-06 | 4 |
| 消融 `m3_ablate_m2`（≈ Mamba-2 式递推） | 467,842 | 0.2601（-0.0018 [-0.0028, -0.0007]） | 76 min | 0.805 / 0.938 ms | 68.0 KB | 单步，0.352 ms，1.3e-06 | 1 **（胜出）** |

\* 预训练耗时是在共享机器、多任务并行下测的（GRU 那一行是第三阶段测的），只能看量级：Mamba-3 MIMO 在 CPU 上明显最慢（约 3.4 小时）。
延迟在训练任务并行时测（loadavg ≈ 5），随机权重，batch 1；ONNX 单步全部能导出，误差 ≤ 1.5e-6。

**按预注册规则的判定**：真实 val loss 最低的是消融 `m3_ablate_m2`，领先第二名超过 0.005，不需要比延迟，所以它胜出。
- 规则本身没有排除项，我们按字面执行，把消融也当作候选。消融在训练前被定位为"廉价对照"，"它也算候选"是看到结果之后才明确的，这一点我们如实说明。
  如果只在用户指定的四个主干里选，胜出的是 Mamba-3 SISO。
- 也就是说：**在这个规模和数据量下，Mamba-3 相对 Mamba-2 式递推新增的梯形离散化和 RoPE 没有带来好处**；MIMO（秩 4）在公开数据上
  VAP loss 最好，但真实数据微调后不如 SISO，而且 CPU 训练慢得多。
- 测试集（定性）：胜出主干和 GRU 相比，各头差异的 95% CI 全部跨 0，测试 VAP loss 也没有显著差异；四个新主干都**没有**在测试集上一致地超过 GRU。
  公开测试流上，三个 SSM 变体的 VAP loss 显著好于 GRU，但幅度很小（约 −0.002，相对 0.7%）。
- 最终配置 = 胜出主干 + 文本情绪特征。和 GRU 相比，测试集上说 / 等 / 不说（`y_act`）、续话、人类接话在"没见过的群"切分上显著变好，
  续话在时间切分上略差（CI 触及 0），其余跨 0。
- 部署建议：任何一个主干的单步都在 2 ms 以内，延迟都不是瓶颈。GRU 最快、状态最小（1.5 KB），胜出主干的 ONNX 单步 p95 约 0.35 ms。

## 4. 4C 连续体记忆（影子回放）

在胜出主干（`m3_ablate_m2`）上做（同样也在 Mamba-3 SISO 和 GRU 上做过，结论一致）。配置网格（层级组合 × 是否惊奇度加权 ×
会话级学习率）只在验证流上按 VAP loss 选，测试流只评一次；另外固定报告"三级都开"的完整 CMS。

**公开流（只用公开数据预训练的主干，5 个公开来源的 pub_test 流，60,888 个事件）**，Δ = 适配后 − 静态的 VAP loss（越负越好）：

| 配置 | 全部事件 | 每条流前 16 个事件 | 前 64 个事件 | 每事件额外开销 p50 / p95 |
|---|---|---|---|---|
| 验证选中（只开会话级，无惊奇度加权） | −0.00037 [−0.00109, +0.00012] | +0.00008 [+0.00001, +0.00018] | −0.00013 [−0.00059, +0.00019] | 0.81 / 1.19 ms |
| 完整 CMS（会话 + 群 + 部署三级） | −0.00034 [−0.00110, +0.00018] | +0.00008 [−0.00001, +0.00020] | −0.00013 [−0.00059, +0.00020] | 0.93 / 1.25 ms |

- 公开流上基本没有效果（CI 跨 0；刚开始的十几个事件里还略差一点点）。
- **真实流（定性，数字在私有报告）**：3 个种子在两个测试切分（没见过的群、见过的群的后续时间段）上 VAP loss 都有
  **很小但显著**的下降（相对静态模型约 0.1–2%）；"用回放结束时的群级 / 部署级状态重新打分"也略好于静态，没有出现遗忘或漂移变差。
  但 6 个决策头（EOT、续话、被叫、说 / 等 / 不说、重检、接话）在测试集上都**没有**显著变化——自监督 VAP 目标上的改进没有传到决策上。
- 在胜出主干和 SISO 上，验证集一律选了"不加惊奇度加权"（GRU 的 3 个种子里有 1 个选了加权）。
- 结论：保持影子模式；对"何时说话"的决策没有可测的影响，暂不上线。

## 6. 局限

- 真实数据仍然很少（验证集几百行），主干之间 val loss 的差距与种子间差异同一量级；测试集上没有一个主干在所有头上一致变好。
- 胜出判定在看到消融结果之后才明确"消融也算候选"（规则本身没有排除项，我们按字面执行，见第 3 节）。
- 中文语音情绪没有人工标注数据，只能靠教师蒸馏，效果接近没有。
- 4C 只做了影子回放；改进量很小，暂不建议上线。
