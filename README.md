# tidal 潮汐

tidal is only the subconscious and below-subconscious memory layer. It stores specific text facts and adds a residual into a frozen causal language model. Turn-taking, speaking decisions, and multimodal perception belong to the brain layer (growbrain). tidal only supplies memory signals.

The design prefers a human-like memory, including partial and fuzzy effects, over a store that is as useful as possible. Each mechanism below is tied to a neuroscience paper. The fit numbers are not the paper's numbers.

Memory vectors are text-only and modality-agnostic. A key and a value are residuals of text. The default width is growbrain `d_model` 192. `mem_dim` 64 is the growbrain injector slot, not this width. An explicit SmolLM2 model is still constructible at hidden 576. They do not read image, audio, video, or other modality features. Each stored slot has `modality`. Text-only live writes store `text` and a zero fingerprint; growbrain may pass `audio`, `image`, `fused`, or `none`.

The longer account is [docs/architecture.md](docs/architecture.md).

Any pull request that changes behavior, mechanisms, constants, or the interface must update `README.md` and `docs/architecture.md` in that same pull request (what changed, the citations, and the held numbers). A pull request with stale docs is not mergeable.

## Implemented memory

`tidal/episodic.py` `EpisodicStore` is the slot list. One fact is one slot. The same identity overwrites that slot. Capacity is 256, then FIFO. Key cosine does not merge slots. A different identity is merged only when the group matches, the relation is the same non-empty string, and the surface token Jaccard is at least `REPEAT_JACCARD` 0.85.

`tidal/llm_memory.py` `LLMMemory` writes those slots from growbrain stage0 `e1_base_rebalance` when that checkpoint can be loaded. The inject layer is 2 of 4, and the packet width is `d_model` 192. `mem_dim` 64 is not that width. `LLMMemory(model_name="HuggingFaceTB/SmolLM2-135M")` uses layer `n_layers // 2` (layer 15, hidden 576) and loads `tidal/llm_inject_smollm2_135m.pt`. The fact text is not copied into the prompt. Generation does not broadcast a mixture. The cue is the per-token hidden state at the inject layer. One slot whose raw cosine with that cue clears theta 0.32 is the winner, ranked by `(log strength, separated cosine, -index)`. Near-neighbor keys are orthogonalized only as that ranking view. The residual on that token is `lambda * a * s * c * u * gain * (scale(v) + MLP(scale(v)))`, with `a = a_trig * fan_factor * decay`, `scale` fixed at 1, `gain = 1 + 2 tanh(w · normalize(k))`, and `u = 1 + tanh(valence)`. `lambda` is 0.3 and is not part of the exported activation. `fan_factor` is `max(0, (S - ln n) / S)` with `S` 1.45. The half-life is 30 tokens. `activation_weights` still implements the earlier mixture (`MIX_K` 4, `MIX_TEMP` 0.05). Generation does not call it. Retrieval-induced forgetting follows the triggered winner. The value is an answer-span pool. A phone or a birthday is concatenated slices of that span. When the prompt is completing that relation, the emitted string is reconstructed from the slot's residue, strength, age, and valence. A fresh high-strength calm slot can match the written spelling. A weak, old, or strongly valenced slot keeps the gist and changes a peripheral field.

Shipped constants, fit on a fit bank and not retuned on held-out: polarity span 2, valence span 1 and step 0.25, clock span 0.25 with tick `pi/16`, McGaugh consolidation span 0.25 on above-baseline arousal times `|valence|`, pattern-separation tau 0.90 and span 0.25 on near-neighbor key cosine, surprise window 32 at quantile 0, replay every 32 accepted writes with strength `0.5 ** age` and one refresh, RIF span 0.05 on the other same-relation candidates that cleared theta, with a closer companion scaled more, once per cue retrieval event and not once per token. A different relation is not scaled. The fan factor scales activation down and does not clear a trigger.

Cue retrieve orthogonalizes near-neighbor keys as a ranking view. Cosine at or above 0.90 is a collision. The unique part of each stored key is amplified, then the original L2 norm is restored. Theta and the candidate set still read raw key cosine. Live `remember` stores the raw key. Yassa and Stark (2011) review dentate gyrus pattern separation. https://doi.org/10.1016/j.tins.2011.06.006 Wixted (2004) reviews interference as a cause of forgetting. https://doi.org/10.1146/annurev.psych.55.090902.141555 The tau and the span are a hypothesis. No grid was run.

The score is only implicit influence: the continuation margin against no memory, summarized as Cohen's `d_z`. Explicit recall, an exact phone or birthday string, is reported separately and is not the score.

## Language-model backend

tidal calls four hooks. The memory layer still chooses the winner, the fan, the decay, and the residual. The backend runs the model and adds that residual.

- `encode_hidden(text) -> (hidden, encoding, logits)`. One forward. `hidden` is the inject-layer residual, float32 `[T, H]`. `logits` are from that same forward. The forward does not add a memory residual.
- `encode_cue(text) -> cue`. Pre-add inject-layer rows, float64 `[T, H]`. It does not inject and does not change the store. `encode_key_hidden(text) -> (hidden, encoding)` is the key-span form. When the stack matches `LlamaModel.forward`, it runs the decoder prefix through the inject layer. Otherwise it uses `encode_hidden` and drops the logits. Those rows match `encode_hidden`.
- `answer_nll(logits, token_ids, answer_mask) -> float`. Total answer-token NLL, in nats, from logits `encode_hidden` already returned. It does not run the model. Position `i` is scored from `logits[i - 1]`. The stored value and this NLL share one forward.
- `inject_residual(output, residual, *, broadcast=False, batched=True)`. Adds a residual into a decoder-layer output. `broadcast=False` adds a numpy residual `[batch, steps, hidden]` at the same index, in the layer output's dtype and device. `broadcast=True` adds one vector on every position. Only teacher-forced loss uses the broadcast. When the retrieval residual is all zeros, the hook returns None and does not call inject, so the layer output object stays the one the block produced.

`GrowbrainBackend` is the default. `LLMMemory()` selects it for stage0 `e1_base_rebalance` and runs `model(idx)` at inject layer 2 once that checkpoint can be loaded. Until then the constructor raises. It does not load SmolLM2 in its place. `encode_hidden(text)` is that text forward. It is not `TidalAdapter.encode_hidden(vec)`, which projects an exported packet from `d_model` 192 to `mem_dim` 64 on the growbrain side. tidal exports the packet and does not call that projection. The episodic store and the key center use `d_model`, not `mem_dim`.

Stage0, with no `expand_d`, pins `d_model` 192, `mem_dim` 64, `mem_key_dim` 32, `inject_layer` 2, `n_layers` 4, and `head_dim` 48. A later checkpoint's `cfg.d_model` replaces 192. ## Reconstructive recall

Phone and birthday spelling is no longer a copy of the stored string. At encode time a `+1-AAA-EEE-LLLL` phone or a `Month D, YYYY` date becomes a residue of integers. Recall reads that residue with the slot's strength, age, and valence. `answer` remains the identity string that reconsolidation checks. It is not the recall source. The value vector is not turned into the spelling. No cue-export field is added. The live `interface_version` is 5.

Exact reassembly requires strength at least 0.8, age at most 0, and absolute valence strictly below 0.75. Strength below 0.4, or age at least 4, replaces the peripheral field. Every other finite triple slips that field's order. For a phone the country code, the area, and the exchange stay; the line is peripheral. An order slip swaps the line's last two digits, or adds one to the last digit when those two match. A loss adds 1111 modulo 10000. For a birthday the month and the year stay; the day is peripheral. An order slip swaps the day digits when that day is still in 1–27 and is different, otherwise it steps to the neighbor inside that range. A loss sets the day to 1, or to 2 when the day was already 1. Age is the consolidation counter already on the slot. It is not wall time and it is not the circadian angle. This vocabulary has no synonym, so the errors are that order slip and that detail loss. The thresholds, the offset, and the gist split are a hypothesis. No grid was run.

## Signals exported to growbrain

The per-token cue export is what generation injects. `GrowbrainBackend.encode_hidden(text)` is the text forward. `TidalAdapter.encode_hidden(vec)` is the other line: growbrain projects `vec` from `d_model` to `mem_dim`. tidal does not call it. `vec` is float32 `[1, T, d_model]`. Stage0 pins `d_model` at 192. Each exported token carries:

- `memory_id`
- `vec`
- `activation = a_trig * fan_factor * decay`
- `strength*confidence`
- `valence`, exported as `u - 1`
- `circadian`
- `triggered`
- `modality`, currently always `text`
- `sleep_pressure`, process S in `[0, 1]`
- `source`: `cue`, `spontaneous`, or `none`
- `arousal`, LC-NE scalar in `[0, 1]`
- `fingerprint`, float32 `(32,)`, cue winner (zeros when none)
- `fusion_confidence`, float32 scalar in `[0, 1]`, last-token / sample-level; 0 when no fusion; `LLMMemory.refresh_fusion_confidence` writes a known value in `(0, 1]` through `set_fusion_confidence`
- `interface_version` 7

`source` is `cue` or `none` on the cue path. `spontaneous` is a no-cue offline tick. The same fields are exported on each offline tick. `decay` is `exp(-dt / tau)` when no wall time has passed since the trigger, and otherwise the lower of that factor and `exp(-elapsed / wall_tau)`. The drifted internal clock is not an exported field. The live `interface_version` is 7. `mem_dim` 64 is not a field and is not the `vec` width. tidal only supplies these signals. Turn-taking, speaking decisions, and multimodal perception belong to the brain layer (growbrain).
